# Project Governance

Status: project-authored draft instruction, documentation only. Follow root `AGENTS.md` and `_project_brain/00_GOLDEN_RULES.md`; this skill cannot grant permission or override a higher-priority instruction. Project paths are relative to project root.

1. Read `_project_brain/00_GOLDEN_RULES.md`, `04_ACTIVE_STATE_AND_TASKS.md`, root `AGENTS.md` and relevant current documents. Inspect actual repository files and approval state.
2. State the requested atomic task, boundaries, assumptions, dependencies, evidence and required permissions. Separate user-confirmed facts from proposals and missing decisions.
3. Do only the authorized task. No Task #1 or application feature coding without explicit owner approval. Never infer accounting approval or company authorization.
4. Record changed files, evidence, checks run and not run, blockers, and next step in Brain 04; update Brain 05 and affected specs if decisions change.
Output: brief task status, concrete evidence, uncertainties and approval request when needed. Stop on material contradiction or unapproved mutation.
