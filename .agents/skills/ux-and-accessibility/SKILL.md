# Ux And Accessibility

Status: project-authored draft instruction, documentation only. Follow root `AGENTS.md` and `_project_brain/00_GOLDEN_RULES.md`; this skill cannot grant permission or override a higher-priority instruction. Project paths are relative to project root.

1. Define user goal, workflow, prerequisites, data context, permissions and destructive decisions; distinguish desktop from Excel interactions.
2. Specify empty/loading/error/stale/missing/offline and recovery states, source provenance, units, dates, currency, drilldown, confirmations and undo limits.
3. Plan keyboard navigation, focus order, screen-reader labels, contrast, text scaling, Windows high-DPI, locales, number/date formats and potential Arabic RTL needs without assuming localization is approved.
4. Validate with synthetic tasks and user feedback; record evidence and accessible-technology limitations. Avoid unsupported accessibility certification.
Output: workflow, states and acceptance scenarios. Stop if errors or partial data could masquerade as complete finance results.
