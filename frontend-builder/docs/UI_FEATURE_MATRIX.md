# Atlas FP&A — UI Feature & Boundary Matrix

**Status:** Interactive UI prototype (`frontend-builder/`) · **Last updated:** 20 November 2026  
**Scope:** Maps UI prototype capabilities against the long-term FP&A Workspace product requirements (`fpa-documentation/`).

Status key:
- **`implemented`** — Interactive UI workflow implemented with synthetic/in-memory state in `Atlas FP&A`.
- **`partial`** — UI preview or illustrative template exists, while underlying financial engine, parser, or data remains unsupplied.
- **`not implemented`** — Production capability intentionally omitted from this frontend prototype; requires separate stack approval and implementation.
